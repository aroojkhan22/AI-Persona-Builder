# 🔥 AI Persona Builder

An interactive and animated web application that generates a **digital persona** based on user skills and personality traits.

---

## 🚀 Features

- ✨ Add and manage skills dynamically  
- 🎚️ Adjust personality traits (Confidence, Creativity, Discipline)  
- 🤖 AI-generated avatar based on input  
- 🎭 Smart persona titles (Creative, Leader, Builder, etc.)  
- 🎬 Smooth animations using Framer Motion  
- 🌌 Modern aesthetic UI  

---

## 🧠 How It Works

1. Enter your skills  
2. Adjust the sliders  
3. Instantly generate your digital persona  

---

## 🛠️ Tech Stack

- Next.js  
- Tailwind CSS  
- Framer Motion  
- DiceBear Avatar API  

---

## 💼 Use Cases

- Personal branding tools  
- Portfolio projects  
- Fiverr / Upwork gigs  
- UI/UX showcase
